# ARYA releases

Downloads for **ARYA** (Agent Resource & Yield Analytics): your coding agents and your
team's tools, in one window.

Get the latest version from [Releases](https://github.com/GoTbraiN/arya-releases/releases/latest):

| System | File |
|---|---|
| macOS, Apple silicon | `ARYA-mac-arm64.dmg` |
| macOS, Intel | `ARYA-mac-x64.dmg` |

Windows and Linux are coming soon.

ARYA isn't signed with Apple yet, so the first time you open it, right-click ARYA in
Applications and choose **Open**.

This repository only holds the installers; they are built and published automatically.
